## Decisions the spec did not cover

1. **How the canvas learns the token colors.** `getComputedStyle(el).getPropertyValue('--color-accent')` returns the unresolved `light-dark(#…, #…)` token stream, so it is useless. `.hero-net` instead carries `color: var(--color-accent)` and `border-color: var(--color-violet)` (border-width 0), and the class reads `styles.color` / `styles.borderTopColor` back resolved. A `MutationObserver` on `documentElement`'s `data-theme` re-reads them.
2. **Alpha via `ctx.globalAlpha`, not `rgba()` strings.** `scripts/check-tokens.ts` fails on the literal `rgba(` anywhere outside `app.css`, so the mock's per-line string building was not an option. Setting `strokeStyle` once per group and modulating `globalAlpha` is also cheaper — it is most of why the frame time came in so low.
3. **The console rect comes from the `offsetParent` chain**, not `getBoundingClientRect`. Offsets ignore transforms, so the card's boot `translateY(24px) scale(.96)` cannot drag the anchors, and they are scroll-invariant by construction. Walking the chain up to the section keeps it correct regardless of which ancestors are positioned.
4. **Camera rotation.** The mock reached ±.075 rad through an accumulated-delta hack; `MOTION_SPEC` says ±.15. `cameraAngles` returns the spec's ±.25 tilt / ±.15 rot directly and the class eases toward it — same feel, no hidden state.
5. **`asteriskTarget` is deterministic.** The mock jitters arm angle and radius by ±.05/±.04; the spec's signature has no `rand`, and the acceptance criterion asks for exact symmetry, so the jitter is gone.
6. **`mountNetwork()` owns the reduced-motion guard**, so "no element is ever created" is a unit test rather than an assertion about an `.astro` script.
7. **More math functions than the spec listed.** The eight named ones plus `fade`, `lerp`, `median`, `cloudCenter`, `consoleAnchors`, `insideCard`, `nearestPoint`, `commandPulses`, `ellipsoidRadii`, `focalLength`, `rotateX`, `asteriskRadius`, `verticalDrift`, `twinkle`, `nodeRadius`, `nodeAlpha`, `cursorPull`, `cameraAngles`, `rotationStep` — that is what "no arithmetic worth testing in the class" costs. What stayed in the class: `Math.hypot` inside the draw loops (geometry the loop must do anyway) and the alpha combination `min(.9, base + cursorBoost + flash·.5)`.
8. **Canvas extent.** `MOTION_SPEC` §3 says 100vw × 100vh; spec 07's Context section says `inset: 0` on the hero section. I followed spec 07 — the canvas is the size of the hero (1440×994 at this viewport), which is also what makes the `mask-image` fade land where the hero ends.</result>
