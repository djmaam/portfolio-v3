## Decisions the spec did not cover

1. **The lead is inline spans, not flex items.** The spec asks for `display:flex; flex-wrap:wrap; gap:0 .26em` *and* for the sentence to copy with its spaces. Those conflict: a flex item is a block-level box, and browsers serialize block boxes to the clipboard with line breaks, not spaces. I kept the spans and put the separating space inside each word (`" interesa"`), so layout, wrapping and per-word opacity are unchanged while the clipboard gets the real sentence — verified above. Manrope's word space is ≈ the .26em the design asked the gap to be.
2. **Grid breakpoint.** `repeat(auto-fit, minmax(min(100%,300px),1fr))` plus a content column spanning 2 tracks creates an *implicit* third track at mobile widths and overflows. So the grid is a single column below 720px (the breakpoint `DESIGN_SPEC` §5 already sanctions) and the auto-fit grid above it, with `.content { grid-column: 2 / -1 }` — which never creates an implicit track.
3. **Card typography**: `n` → `text-label-sm` accent, `h` → `text-card-title`, `d` → `text-body` dim. The mock's raw 17px/14px are not tokens; `DESIGN_SPEC` §2 allows 15–18px for card body and 19–22px for card titles, so no new type token was added.
4. **Noticed, not fixed (out of scope):** the nav is `position: sticky`, so a *native* fragment jump (JS disabled) lands the section under the nav. A site-wide `scroll-margin-top: var(--nav-h)` would fix it, but that belongs to the nav/base block rather than to one section — flagging rather than adding it in About alone.
