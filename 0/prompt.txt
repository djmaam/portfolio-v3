## Decisions the spec did not cover

- **`glow` is `"transparent"`, not absent, on the four past roles.** "An item whose `glow` is set" therefore had to become `job.glow !== 'transparent'`. The test asserts both that the content still has exactly one such job and that the component compares against `transparent` rather than emitting anything.
- **`check-tokens` scans comments.** My first version explained the trap by quoting `#3EE7FF` and `rgba(62,231,255,.6)` in a code comment — the checker flagged both. Reworded to describe them instead. Worth knowing for the other three agents.
- **The scramble needs an `IntersectionObserver` of its own.** `bindReveals` drives opacity/transform and cannot carry a text callback, and the spec forbids a second reveal implementation, so the section observes `[data-company]` directly and calls the shared `scramble(el, 1000)`. `reveal.ts`'s doc comment calls itself "the site's only `IntersectionObserver`" — that claim is now slightly stale, but I left the file untouched to avoid a conflict with the parallel branches. Someone should reword it after the merges.
- **Hover styling.** The mock's timeline items are borderless, but spec 10 requires `translateY(-4px)` + accent border + shadow. Compromise: the card is transparent-bordered at rest (mock look) and materializes `--color-surface` + accent border + shadow on hover. `data-reveal` sits on the `&lt;li&gt;`, the transform on the `&lt;article&gt;` below it.
- **Dropped `revealDelay`.** Timeline items are a full card apart vertically and each crosses the threshold on its own, so an index stagger would just make the fifth item 440 ms late. No `math.ts` import.
- **`white-space: nowrap` + ellipsis on the company name.** The scramble preserves length but not glyph widths, so a wrapping name could rewrap mid-animation; the ellipsis is the safety valve in the 260 px minimum column.
