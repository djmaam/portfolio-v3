### How I work

|                                                                             |            |                                                                         |                          |
| :-------------------------------------------------------------------------: | :--------- | :---------------------------------------------------------------------- | :----------------------- |
| <img src="https://img.shields.io/badge/01-FF5C5C?style=flat-square" alt=""> | **Idea**   | Understand the problem, who it affects and what solving it well means.  | `conversation · context` |
| <img src="https://img.shields.io/badge/02-FF9F43?style=flat-square" alt=""> | **Spec**   | Define the what and the why, with verifiable acceptance criteria.       | `SDD · markdown`         |
| <img src="https://img.shields.io/badge/03-FFD64D?style=flat-square" alt=""> | **Plan**   | Architecture, tasks, and which agent owns each one.                     | `plans · skills`         |
| <img src="https://img.shields.io/badge/04-9BE15D?style=flat-square" alt=""> | **Agents** | Parallel execution with continuous review of code and design.           | `Claude Code · Codex`    |
| <img src="https://img.shields.io/badge/05-3DDC84?style=flat-square" alt=""> | **Ship**   | Validate against the spec and take it to production with observability. | `CI/CD · observability`  |

The spec is the contract. Agents execute. I design the architecture, review the output and make the calls.
